# Allen Class 8 — Daily Practice & DPP Library

A structured Class 8 foundation practice repository for Physics, Chemistry, Mathematics and Biology.

## Start here
1. Download the complete [Daily Practice Pack (ZIP)](DPP_Daily_Practice_Pack.zip).
2. Extract it on your device.
3. Open `dpp_practice_app.html` in Chrome, Edge, Firefox or Safari.
4. Select **Start today's set**. The current schedule provides up to 5 questions per subject (20 total).
5. Use **Revise mistakes** to retry questions answered incorrectly.

## Repository contents
- Existing chapter-wise RACE solution PDFs are kept in the repository root.
- [Complete daily practice pack](DPP_Daily_Practice_Pack.zip) — app, question bank, extracted text, inventory and scripts.
- [Pack guide and verification status](DAILY-PRACTICE/README.md).

## Subjects and chapters in the practice pack
- **Physics:** Electricity; Force and Laws of Motion; Gravitation; Magnetic Effects of Electric Current; Motion; Work, Energy and Power.
- **Chemistry:** Atoms and Molecules; Carbon and Its Compounds; Metals and Non-Metals; Structure of the Atom.
- **Mathematics:** Absolute Value Function; Circles; Coordinate Geometry; Linear Equations in Two Variables; Linear Inequality; Number System; Polynomials; Quadratic Equations; Trigonometry and Its Applications.
- **Biology:** Cell; Control and Coordination; Heredity; Reproduction in Human; Tissue.

## Important accuracy note
The included app currently contains 35 auto-checked questions marked for verification. The source pack's plan reports approximately 600 candidate MCQs across 170 DPP sheets; these are **not all verified or included in the app yet**. Do not treat the remaining extracted text as a checked answer bank. See the detailed guide before relying on answers.

## Daily routine
A suggested 5:00 PM daily study session is to complete the available subject sets, read explanations, and revise mistakes. Progress is stored locally in the browser used to run the app.
